Files for the GOTEK floppy emulator

This  is  a thumb drive set of files for my Kaypro 2x  version  3 
computer. It has the universal board and universal ROM (81-478A). 
I  replaced the ROM with the KayPLUS ROM.  This allows  different 
disk drive types and formats. Most of the files here require the 
KayPLUS ROM. 
It  is  recommended to reset are reboot for each  floppy  imsage. 
This loads the sysgen for that disk. Most files are DSDD 360K
Starting at #50, the disk format is set to 3.5" 776K format.

This was done by choosing the drive type in KayPLUS configuration 
to  be  3.5"  and  then  using the  KayPLUS  Format  Utility  for 
MICROCode 1k DD. This will create an 80 track 776K disk.
